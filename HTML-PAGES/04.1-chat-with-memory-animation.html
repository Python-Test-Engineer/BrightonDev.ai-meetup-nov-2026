04 · Stateful conversations

Chat with memory

The model is stateless. The browser creates the feeling of memory by resending the conversation and keeping a copy between visits.

ReadyPress Play to trace a message through the app, model, and browser storage.
Space = play/pause · → = next · R = reset

The app—not the model—owns the conversation. Each request includes prior messages, and the browser stores them for the next visit.

Try the conversation

Ask a follow-up question, refresh the page, or clear the saved chat to see the browser-side memory in action.
